# Authors

This file lists the authors and major contributors of the EvoRule project.

The EvoRule project aims to build a reactive execution engine that **accepts and runs JSON datasets only**.

> All project code, documentation, rules, and design decisions were completed by him independently.

## Design Principles

The core design principles of EvoRule:

- Rules as data
- Self-explanatory engine
- Fully traceable
- Zero hidden logic
- Immutable state
- Deterministic execution

## How to Be Listed

- **Code contributors**: significant code contributions will be added to this file. If you would like to be listed, please include your preferred name and GitHub username in your PR.
- **Rule contributors**: if your business rules are merged into the `rules/` directory, you will be credited in this file and in the rule metadata.
- **Documentation contributors**: substantive improvements to the documentation will also be credited.

To request an addition or modification to this file, please submit a PR or an Issue.

---

## The Value of Contributions

The EvoRule project follows the spirit of its own philosophy — the value of a contribution is based on its **content** and its consistency with the project principles (transparent / auditable / deterministic / JSON-only), not merely on volume.
