# evorule-mcu

EvoRule embedded (MCU) no_std kernel: compact rule pack + RAM WAL + tick clock + sync executor.

- `no_std` + `alloc`, no std dependency; audit-chain hashing goes through the `evorule-audit-chain`
  single source of truth, producing WAL rows and chain-tail hashes byte-identical to the std host (reactor) for the same input.
- Compact rule pack (`.evopack`): a postcard-encoded core_eval rule array (generated by the host
  compiler `evorule-cli`).
- RAM WAL: `FactWalStore` isomorphic semantics (append-only, hash-chain fields preserved verbatim,
  write-ahead precedes state update).
- Sync executor: event (instruction) → `execute_transition` → audit (StateTransition /
  TransitionTrace / Stable and other fact-emission semantics consistent with the reactor main loop) → RAM WAL.
- `io_request` meta instruction: pause-resume protocol — after the IoRequest fact enters the chain, `run` returns
  `McuError::IoPaused`; the board performs the I/O via `IoBridge` and calls `resume_io` to continue
  (the result is injected into `__io_results__.{io_type}` → the original instruction is re-pushed → the resume step clears the container,
  mirroring the reactor v0.3.1 I/O resume semantics).
