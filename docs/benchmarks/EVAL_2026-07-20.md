## 7. Issues Found

### 7.1 Client Compatibility (NOT a server bug)

- **PowerShell 5.1 `Invoke-WebRequest` auto-decompresses gzip**, so saved file is not raw gzip bytes
- **Recommendation for SDK docs**: explicitly say "use `curl --output` or .NET HttpClient for raw bytes"
- **Workaround for now**: use `curl.exe` (bundled with Windows 10+)

### 7.2 Small Data Compression

- 1478 bytes JSON → 744 bytes gzip (50.3%)
- Hash strings have high randomness (not compressible), small data has limited ratio
- **Recommendation**: use compression for large audit chains (>100 entries), JSON for small

### 7.3 Log Level

- P06 "验证通过" is at debug level (invisible in production info-level)
- **Recommendation**: keep as-is (avoid log explosion); "验证失败" is error-level (logged in production)
