# Community Contribution Grant Records (Channel D)

This directory holds the issuance records of [CONTRIBUTION_GRANT.md](../../CONTRIBUTION_GRANT.md) (Channel D).
Each record = one grant asset inventory (file-by-file, version-anchored) + issuance date + copyright holder's signature.
Once issued, records are anchored by the main repository's git history and are tamper-proof (append-only; historical records are never edited or deleted).
