# tutorial/ — 教学文档

> **面向第一次接触 evorule 的开发者**,手把手带你跑通。

适合:刚装好、从零开始学的同事或外部用户。

## 写什么

- 从空环境开始,**一步步**带你完成一个完整任务
- 每一步都到"我能照着做"的颗粒度(命令、点击、期望结果)
- **不**假设你已经懂 evorule 的任何概念

## 不要写在这里

- ❌ "怎么解决 X 问题" → 去 [how-to/](../how-to/)
- ❌ API 字典、字段说明 → 去 [reference/](../reference/)
- ❌ "为什么这么设计" → 去 [explanation/](../explanation/)

## 命名规范

`NN-标题.md`(如 `01-quickstart.md`),NN 从 01 起,保证学习顺序。

# tutorial/ — Tutorials

> **For developers touching evorule for the first time**, a hands-on walk-through that gets you up and running.

Intended for: colleagues or external users who have just installed evorule and are learning it from scratch.

## What belongs here

- Start from an empty environment and **walk through** a complete task step by step
- Every step is written at "I can follow along" granularity (commands, actions, expected results)
- Does **not** assume you already know any evorule concepts

## What does not belong here

- ❌ "How do I solve problem X" → go to [how-to/](../how-to/)
- ❌ API dictionary, field reference → go to [reference/](../reference/)
- ❌ "Why is it designed this way" → go to [explanation/](../explanation/)

## Naming convention

`NN-Title.md` (e.g. `01-quickstart.md`), with NN starting at 01 to guarantee the learning order.
